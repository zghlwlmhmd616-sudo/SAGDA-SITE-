# سنتر سجدة للزي الشرعي — نسخة Frontend أولية

هذه نسخة واجهة تعمل مباشرة في المتصفح، وتشمل:
- أقسام المنتجات
- البحث
- موديلات وعروض أسعار
- نافذة تفاصيل وطلب
- تقييمات
- سلة
- وضع داكن/فاتح
- لوحة إدارة تجريبية
- طلبات وشات محفوظة محليًا
- المنتدى والفواتير وعجلة الحظ كواجهات أولية
- زر المساعد "سجدة"
- تصميم متجاوب للموبايل والتابلت والكمبيوتر
- اللوجو المرفق

## التشغيل
افتح `index.html` في المتصفح.

## مهم قبل النشر الحقيقي
هذه النسخة تستخدم localStorage للتجربة فقط.
لأن الموقع الحقيقي يحتاج:
1. Backend آمن.
2. قاعدة بيانات للمنتجات والطلبات والعملاء والتقييمات والشات.
3. رفع صور حقيقي للمنتجات وصور إثبات التحويل.
4. تسجيل دخول آمن للمشرف مع جلسات وصلاحيات.
5. تغيير كلمة السر من السيرفر، وليس داخل JavaScript.
6. لوحة تحكم حقيقية للإحصائيات والزوار.
7. خدمة بريد/واتساب أو API لإشعارات الطلبات حسب الخدمة المستخدمة.
8. حماية بيانات العملاء وعدم تخزينها في المتصفح العام.

بيانات المشرف الحساسة لا ينبغي وضعها في ملفات JavaScript مكشوفة عند النشر.
